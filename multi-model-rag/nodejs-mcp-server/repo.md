"Agent‑based systems typically organize memory into a few broad categories that mirror those found in human cognition:


\n\n| **Memory type** | **What it stores** | **Typical role in an agent** |\n|-----------------|--------------------|------------------------------|\n| **Sensory / Perceptual Memory** | Raw sensor data (e.g., camera frames, lidar points, audio samples) that lasts only a few hundred milliseconds. | Provides the initial “snapshot” of the environment that feeds higher‑level processing. |\n| **Short‑Term / Working Memory** | A limited‑capacity buffer that holds current task‑relevant information (e.g., the current goal, recent percepts, intermediate results). | Supports reasoning, planning, and decision‑making that require on‑the‑fly manipulation of a few items. |\n| **Long‑Term Memory** | Persistent knowledge that can be retained indefinitely. It is usually subdivided into: <br>• **Episodic memory** – records specific episodes or events (what happened, when, where). <br>• **Semantic memory** – stores general facts, concepts, and world knowledge. <br>• **Procedural memory** – encodes skills, habits, and action sequences (how to perform a task). | Provides the agent with a history of past interactions, reusable knowledge, and learned behaviors. |\n| **Declarative vs. Procedural Memory** (a higher‑level view) | Declarative = explicit facts (semantic & episodic). Procedural = implicit “how‑to” knowledge (procedural). | Distinguishes between knowledge that can be explicitly recalled versus skills that are executed automatically. |\n| **Shared / Communication Memory** (in multi‑agent systems) | Common data structures or blackboards that agents can read/write to coordinate. | Enables collaboration, information exchange, and collective problem‑solving. |\n| **State / Context Memory** | Current internal state variables (e.g., belief sets, goal stacks, mood/energy levels). | Keeps track of the agent’s own condition and the evolving context of its mission. |\n\nThese categories can be implemented in many ways—e.g., as symbolic KBs, neural networks, reinforcement‑learning tables, or hybrid architectures—but the underlying functional distinction between sensory, short‑term, long‑term (and possibly shared) memory remains a common design pattern for intelligent agents."
